# Portfolio Radar

כלי ויזואלי מקומי למשקיעים: התיק שלך, רעיונות למניות דומות עם ציון פוטנציאל, לוח דוחות קרובים וניתוח דוחות מה-SEC. הכול רץ אצלך במחשב. אין חשבון, אין מפתח API ואין ספריות להתקין.

## הפעלה

צריך Python 3.8 ומעלה.

```bash
git clone <this repo> && cd portfolio-radar
cp config.example.json config.json   # שם ואימייל אמיתיים, SEC דורש זיהוי
python3 server.py                    # נתונים חיים, נפתח ב-http://localhost:8765
```

רוצה לראות קודם בלי אינטרנט? `python3 server.py --demo` מריץ על צילום מצב אמיתי מ-20.10.2026: מחירים של 19 מניות, ודוחות SEC של Apple ו-Coca-Cola.

אפשרויות נוספות: `--port 9000`, `--no-browser`.

## מה יש בו

| לשונית | מה עושה |
| --- | --- |
| **התיק שלי** | חיפוש מניה לפי שם או סימול (`Apple`, `KO`, `TEVA.TA`), כמות ומחיר קנייה. שווי, רווח/הפסד, שינוי יומי, גרף 3 חודשים, ציון ותאריך הדוח הבא |
| **רעיונות** | מניות ש-Yahoo מקשר למניות שבתיק ("people also watch"), מדורגות לפי ציון פוטנציאל, עם תגיות כמו "ליד שיא שנתי", "מכור-יתר" ו"צמיחה דו-ספרתית" |
| **דוחות** | ציר זמן של דוחות ב-4 השבועות הקרובים (מלוח הדוחות של Nasdaq) למניות שבתיק ולרעיונות. לחיצה פותחת ניתוח של הדוח האחרון |

לחיצה על מניה פותחת כרטיס מלא: גרף מחיר עם ממוצע 50 יום, תשואות, RSI, טווח 52 שבועות, פירוט הציון, וניתוח 6 רבעונים אחרונים מה-SEC (הכנסות, שולי רווח ו-EPS מול שנה קודמת, עם סיכום בעברית וקישורים לדוח ולהודעת התוצאות).

## ציון הפוטנציאל

סכום שקוף של כללים פשוטים, 0 עד 100. כל נקודה מוסברת בכרטיס המניה.

| רכיב | נקודות |
| --- | --- |
| מגמה: מחיר מול ממוצע 50 ו-200 יום, והאם הממוצע עולה | 25 |
| מומנטום: תשואה ב-3 חודשים | 20 |
| מיקום בטווח 52 שבועות (תיקון בתוך מגמה עולה מקבל הכי הרבה) | 15 |
| RSI (14) | 10 |
| צמיחת הכנסות ו-EPS מול שנה קודמת ושיפור בשולי הרווח (רק לחברות שמדווחות ל-SEC) | 30 |

כשחסר רכיב, למשל מניה ישראלית בלי דוחות SEC, הציון מנורמל לפי מה שיש. **זה מדרג גרפים ומספרים, לא חוזה מחירים.**

## מקורות נתונים

| מקור | בשביל מה | הערות |
| --- | --- | --- |
| Yahoo Finance (chart, search, recommendations) | מחירים, חיפוש, מניות דומות | לא רשמי, עשוי להתעכב או להשתנות |
| Nasdaq earnings calendar | תאריכי דוחות | כשמניה לא מופיעה, מוצגת הערכה לפי היסטוריית ההגשות ב-SEC (מסומנת "הערכה") |
| SEC EDGAR (XBRL company facts) | ניתוח דוחות | חברות אמריקאיות בלבד |

תשובות נשמרות ב-`data/cache/` (מחירים ל-15 דקות, דוחות ל-12 שעות). התיק נשמר ב-`data/portfolio.json`. שני הקבצים לא נכנסים ל-git.

## מבנה

```
server.py            שרת HTTP מקומי (ספרייה סטנדרטית בלבד)
radar/market.py      Yahoo: מחירים, חיפוש, מניות דומות, אינדיקטורים
radar/earnings.py    לוח דוחות, ניתוח SEC, סיכום בעברית
radar/score.py       ציון הפוטנציאל
radar/sources.py     מקור חי ומקור דמו
radar/app.py         הלוגיקה שהעמוד מבקש
radar/sec_facts.py   קורא ה-XBRL מ-day-trader-skill (MIT, ראה LICENSE.sec_facts)
web/                 העמוד (HTML/CSS/JS בלי ספריות)
demo_data/           צילום מצב אמיתי למצב דמו ולבדיקות
tests/               python3 -m unittest discover -s tests -v
```
